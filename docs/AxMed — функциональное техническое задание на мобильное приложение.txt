AxMed — функциональное техническое задание на мобильное приложение
Версия 1.0
Дата: 26 августа 2026 года
1. Цель приложения
AxMed — мобильное приложение для взрослых пользователей, которое:
* собирает антропометрические и физиологические показатели;
* принимает ручные измерения и данные подключённых устройств;
* проверяет качество, источник и сопоставимость данных;
* сравнивает показатели с личным обычным уровнем пользователя;
* показывает до трёх наиболее важных выводов;
* объясняет каждый вывод через кнопку «Почему?»;
* предлагает одно конкретное следующее действие;
* формирует персональный План;
* позволяет скачать отчёт и ЭКГ для передачи врачу вне приложения;
* распознаёт потенциально опасные сочетания показателей и симптомов.
Приложение не ставит диагноз по данным потребительских устройств, не назначает лекарства и не меняет дозировки.
2. Границы версии 1
2.1. Пользователи
* Версия 1 предназначена только для пользователей 18+.
* Пользователь младше 18 лет не проходит первичную настройку.
* Педиатрический режим и детские референсы в MVP не реализуются.
Это осознанное отклонение от BLOCK I, где предусмотрен отдельный педиатрический BMI-модуль.
2.2. Роли
В версии 1 есть только пользователь приложения.
Не реализуются:
* врачебный кабинет;
* вход врача;
* внутренний чат с врачом;
* запись к врачу;
* внутренняя проверка ЭКГ врачом.
Пользователь может скачать отчёт или ЭКГ и поделиться файлом через системное меню телефона.
2.3. Другие ограничения
В версию 1 не входят:
* постановка медицинского диагноза;
* автоматическое изменение лекарств, кислорода или дозировок;
* полноценный Sleep Engine;
* собственная многоклассовая AI-диагностика аритмий;
* лечебные диеты;
* лабораторные risk engines;
* диагностика саркопении;
* пользовательский балл восстановления 0–100.

4. Навигация
В приложении четыре нижние вкладки.
Вкладка
	Назначение
	Главная
	Показать, что сейчас важно и что сделать дальше
	Здоровье
	Показать все показатели, измерения, историю и тренды
	План
	Показать действия, цели, сроки и прогресс
	Профиль
	Управлять личными данными, контекстом, устройствами, согласиями и отчётами
	Измерение не является отдельной вкладкой. Оно запускается конкретной кнопкой из «Главной», «Здоровья» или «Плана».
5. Общие правила экранов
5.1. Данные показателя
Рядом со значимым показателем должны отображаться:
* значение и единица;
* дата и время;
* источник;
* устройство;
* контекст измерения;
* качество;
* доверие к источнику;
* свежесть данных;
* состояние личного уровня.
5.2. Основное действие
На одном экране должно быть одно визуально главное действие.
Название кнопки должно точно описывать результат нажатия:
* «Измерить давление»;
* «Добавить окружность талии»;
* «Повторить ВСР»;
* «Скачать PDF»;
* «Поделиться с врачом».
5.3. Кнопка «Почему?»
Кнопка показывает:
* что изменилось;
* с чем сравнивалось значение;
* какие данные использованы;
* источник и качество;
* уверенность вывода;
* почему предложено именно это действие.
Для комплексного вывода показывается максимум три фактора. Факторов может быть меньше трёх.
5.4. Общие состояния
Для экранов с данными предусматриваются:
* загрузка;
* данных нет;
* данных недостаточно;
* данные устарели;
* офлайн;
* синхронизация;
* ошибка;
* плохое качество;
* ограниченное доверие;
* устройство сменилось;
* личный уровень пересчитывается;
* конфликт источников;
* срочное предупреждение.
Отсутствие данных никогда не показывается как нормальное состояние.
Системные проверки выполняются автоматически. Пользователь не должен нажимать «Проверить выполнение» или самостоятельно выбирать медицинский маршрут.
6. Экраны приложения
6.1. Первый запуск и регистрация
SCR-00 — Запуск
Назначение: определить начальный маршрут.
Система:
* проверяет активную сессию;
* загружает локальный профиль;
* находит незавершённый шаг регистрации.
Переходы:
* нет сессии → SCR-01;
* активная сессия → SCR-H01;
* регистрация прервана → первый незаполненный шаг.
При ошибке:
* «Повторить»;
* «Продолжить офлайн» — только при существующей локальной сессии.
SCR-01 — Добро пожаловать
Показывает краткое описание пользы AxMed.
Кнопки:
* «Создать аккаунт»;
* «Войти».
SCR-02 — Регистрация
Варианты:
* email;
* Google;
* Apple.
Кнопки:
* «Продолжить с email»;
* «Продолжить с Google»;
* «Продолжить с Apple»;
* «Назад».
Email ведёт на SCR-02A. Google/Apple после успешной авторизации ведут на SCR-03.
SCR-02A — Подтверждение email
Показывает поле одноразового кода.
Кнопки:
* «Подтвердить»;
* «Отправить код снова»;
* «Изменить email»;
* «Назад».
Состояния:
* код неверный;
* код истёк;
* код отправляется повторно;
* нет сети.
SCR-02B — Вход
Варианты:
* email;
* Google;
* Apple.
Кнопки:
* «Получить код по email»;
* «Войти с Google»;
* «Войти с Apple»;
* «Назад».
SCR-02C — Подтверждение входа по email
Кнопки:
* «Войти»;
* «Отправить код снова»;
* «Изменить email»;
* «Назад».
После успеха открывается SCR-H01.
SCR-03 — О вас
Поля:
* дата рождения;
* пол при рождении.
Система вычисляет возраст на текущую дату.
Кнопки:
* «Продолжить»;
* «Назад».
Переходы:
* 18+ → SCR-04;
* младше 18 → SCR-03A.
SCR-03A — Ограничение 18+
Текст:
«AxMed пока доступен пользователям старше 18 лет».
Кнопки:
* «Исправить дату рождения»;
* «Выйти из аккаунта».
SCR-04 — Согласия
Обязательные согласия:
* условия сервиса;
* политика конфиденциальности;
* обработка данных о здоровье.
Элементы:
* отдельный флажок для каждого согласия;
* ссылка «Открыть документ».
Кнопки:
* «Принять и продолжить»;
* «Выйти».
Согласие на передачу отчёта врачу запрашивается непосредственно перед отправкой файла, а не во время регистрации.
SCR-04A — Согласие не принято
Показывает, без какого согласия сервис не может работать.
Кнопки:
* «Вернуться к согласиям»;
* «Выйти».
SCR-05 — Первые данные тела
Обязательные поля:
* рост;
* вес.
Рекомендуемое поле:
* окружность талии.
Опциональные поля:
* бёдра;
* грудь;
* плечо;
* икра.
Кнопки:
* «Рассчитать профиль»;
* «Назад».
Вычисления:
* BMI;
* WHtR при наличии талии;
* WHR при наличии бёдер.
SCR-06 — Подключение источника
Варианты:
* BIA-весы;
* часы или браслет;
* HealthKit;
* Health Connect.
Показывает:
* какие данные будут считываться;
* какие разрешения нужны.
Кнопки:
* «Подключить»;
* «Пропустить и продолжить вручную»;
* «Назад».
SCR-06A — Источник не подключён
Причины:
* разрешение;
* Bluetooth;
* сеть;
* неподдерживаемая модель.
Кнопки:
* «Повторить»;
* «Продолжить с ручным вводом».
SCR-07 — Первый результат
Показывает:
* вес;
* BMI;
* талию и WHtR;
* WHR при наличии;
* профиль тела простым языком;
* полноту и качество;
* один наиболее полезный следующий замер.
Кнопки:
* «На Главную»;
* «Почему такой результат?».
Внутренние коды профиля P1–P6 не показываются.
6.2. Главная
SCR-H01 — Главная
Порядок содержимого:
1. срочное предупреждение;
2. состояние на сегодня;
3. уверенность;
4. до трёх выводов;
5. кнопка «Почему?» у каждого вывода;
6. одна карточка следующего действия;
7. ближайшая задача из Плана;
8. время обновления и синхронизация.
Примеры главной кнопки:
* «Измерить давление»;
* «Добавить замер тела»;
* «Повторить SpO₂ в покое»;
* «Продолжить сбор ВСР»;
* «Открыть план».
После выполнения действия данные пересчитываются, и пользователь возвращается на обновлённую Главную.
При опасном состоянии срочная карточка заменяет обычное следующее действие.
SCR-H01A — Недостаточно данных
Показывает:
* какого показателя не хватает;
* почему вывод ограничен;
* какой один замер будет наиболее полезным.
Кнопка, например:
* «Добавить окружность талии»;
* «Повторить ВСР»;
* «Измерить SpO₂».
SCR-H02 — Почему такой вывод
Показывает:
* обнаруженный сигнал;
* использованные данные;
* сравнение;
* качество;
* уверенность;
* рекомендуемое действие.
Кнопки:
* «Закрыть»;
* конкретное следующее действие, если оно требуется.
6.3. Здоровье
SCR-Z01 — Здоровье
Разделы:
* Тело;
* Показатели здоровья;
* Активность;
* Температура;
* Восстановление;
* Тренды и история.
У карточки показываются последнее состояние, время и качество.
SCR-V01 — Показатели здоровья
Карточки:
* давление;
* пульс;
* ВСР;
* SpO₂;
* ЭКГ.
У каждой карточки:
* последнее значение или статус;
* источник;
* время;
* качество;
* конкретное действие.
SCR-Z02 — Общие тренды
Фильтры:
* раздел;
* показатель;
* период;
* источник или устройство.
Правила:
* смена устройства отмечается;
* несопоставимые серии не соединяются;
* отсутствие данных не показывается как норма.
Нажатие на точку открывает исходную запись.
6.4. Тело
SCR-B01 — Тело: обзор
Показывает:
* вес и изменение;
* BMI;
* талию;
* WHtR;
* WHR;
* до трёх выводов;
* дату, источник и качество;
* недостающий показатель.
Кнопки:
* «Добавить измерение»;
* «3D-модель»;
* «Состав тела»;
* «Тренды»;
* «Почему?».
STATE-B01A — Недостаточно данных тела
Это состояние SCR-B01.
Примеры кнопок:
* «Добавить окружность талии»;
* «Добавить окружность бёдер»;
* «Подключить BIA-весы»;
* «Повторить измерение состава тела».
SCR-B02 — 3D-модель тела
Показывает параметрическую 3D-модель на основе:
* роста;
* веса/BMI;
* талии;
* бёдер;
* груди;
* сегментарных BIA-данных при наличии.
Элементы:
* «Сейчас»;
* «Раньше»;
* поворот;
* масштаб;
* полнота данных.
При нехватке данных используется нейтральная геометрия. Модель не показывает органы или патологию и не является диагнозом.
SCR-B03 — Состав тела
Группы:
* жир;
* мышцы;
* вода;
* дополнительные показатели;
* сегменты.
Показатели при наличии:
* процент и масса жира;
* мышечная масса;
* скелетная мышечная масса;
* общая вода;
* висцеральный индекс;
* BMR;
* «возраст тела».
Для каждого показателя:
* значение;
* единица;
* дата;
* источник;
* тип данных.
Типы:
* измерено устройством;
* рассчитано производителем;
* рассчитано AxMed.
Кнопки:
* «Добавить измерение»;
* «Посмотреть тренд»;
* «Почему?».
SCR-B06 — Добавить измерение
Способы:
* «Ввести вручную»;
* «Измерить на BIA-весах»;
* «Импортировать из источника».
Новая запись не перезаписывает историю.
SCR-B07 — Ручной ввод
Поля:
* дата и время;
* рост;
* вес;
* талия;
* бёдра;
* грудь;
* плечо;
* икра;
* единицы.
Кнопки:
* «Сохранить и рассчитать»;
* «Отмена».
При необычном значении:
* «Исправить»;
* «Сохранить всё равно».
SCR-B08 — Подготовка BIA
Показывает:
* устройство;
* профиль пользователя;
* инструкции;
* условия измерения.
Система сохраняет:
* модель;
* ID;
* firmware;
* SDK/протокол.
Кнопки:
* «Начать измерение»;
* «Выбрать другое устройство»;

SCR-B09 — Измерение BIA
Показывает:
* соединение;
* этап;
* прогресс.
Сохраняются только завершённые исходные показания.
Кнопка:
* «Отменить измерение».
SCR-B10 — Результат измерения тела
Показывает:
* новые значения;
* изменение к сопоставимому исходному уровню;
* обновлённые выводы;
* источник;
* время;
* качество.
Кнопки:
* «Готово»;
* «Посмотреть тренд»;
* «Почему?».
SCR-B11 — Импорт данных тела
Показывает:
* источник;
* найденные записи;
* даты;
* единицы;
* возможные дубликаты.
Кнопки:
* «Импортировать выбранное»;
* «Выбрать источник»;
* «Отмена».
STATE-B09-01 — Низкое качество или скачок
Причины:
* артефакт;
* резкий скачок;
* смена устройства;
* конфликт источников;
* возможная асимметрия.
Кнопки:
* «Повторить BIA»;
* «Ввести вручную».
До подтверждения сильный вывод не формируется.
SCR-B12 — Тренды тела
Графики:
* вес;
* талия;
* жир;
* мышцы.
Показывает:
* абсолютное изменение;
* процент;
* период;
* смену устройства.
Нажатие на точку → SCR-B13.
SCR-B13 — Детали записи тела
Показывает:
* исходное значение;
* нормализованное значение;
* единицу;
* дату;
* источник;
* устройство;
* качество;
* производные показатели.
Ошибочная запись помечается как заменённая, но не перезаписывается.
Расчёты тела
* BMI = вес / рост².
* WHtR = талия / рост.
* WHR = талия / бёдра.
* Изменение = текущее − исходное.
* Процент = изменение / исходное × 100%.
* Изменения BIA рассчитываются только между сопоставимыми измерениями.
Пороги хранятся в версионируемых серверных таблицах.
6.5. Давление
SCR-BP01 — Давление
Показывает:
* последнее значение;
* домашнее среднее;
* утреннее и вечернее среднее;
* источник;
* доверие;
* качество;
* время.
Дом, клиника, СМАД и wearable-оценка разделяются.
Кнопки:
* «Добавить показания»;
* «История»;
* «Почему?».
После «Добавить показания»:
* «Измерить манжетой»;
* «Ввести или импортировать».
SCR-BP02 — Подготовка
Инструкции:
* отдых 5 минут;
* спина с опорой;
* стопы на полу;
* ноги не скрещены;
* манжета на голой руке;
* рука на уровне сердца;
* не двигаться и не разговаривать.
Кнопки:
* «Готов, начать»;
* «Отмена».
SCR-BP03 — Ручной ввод или импорт
Обязательные поля:
* SBP;
* DBP;
* дата;
* время;
* контекст;
* источник.
Опциональные:
* пульс;
* рука;
* положение;
* модель;
* валидация устройства.
Кнопки:
* «Сохранить показание»;
* «Отмена».
SCR-BP04 — Первое измерение
Показывает подключение и прогресс.
Система сохраняет первое исходное значение.
Кнопка:
* «Отменить».
SCR-BP05 — Пауза
Показывает таймер 60 секунд.
После таймера автоматически открывается SCR-BP06.
SCR-BP06 — Второе измерение
Система сохраняет второе значение и рассчитывает среднее сессии.
SCR-BP07 — Результат
Для манжеты:
* оба значения;
* среднее сессии.
Для ручного ввода:
* одно введённое значение без искусственного среднего.
Для всех:
* контекст;
* источник;
* доверие;
* качество;
* время;
* интерпретация.
Основная кнопка зависит от результата:
* «Повторить после отдыха»;
* «Начать домашний мониторинг»;
* «Подтвердить манжетой»;
* «Связаться со специалистом».
SCR-BP08 — Показание нельзя использовать
Показывает конкретную причину.
Кнопки:
* «Повторить подготовку»;
* «Исправить поля».
Невалидная запись не включается в среднее.
STATE-BP07A — Другие состояния результата
Варианты:
* обычное значение;
* низкое давление с симптомами;
* расхождение дома и клиники;
* выше индивидуальной цели на терапии;
* wearable-оценка требует манжеты;
* данных недостаточно.
STATE-BP07B — Однократно повышено
Показывает, что одного значения недостаточно.
Кнопка:
* «Отдохнуть и повторить».
SCR-BP09 — Повтор и симптомы
Проверяются:
* боль в груди;
* одышка;
* обморок;
* неврологические симптомы.
Кнопки:
* «Повторить измерение»;
* «У меня есть опасные симптомы».
SCR-BP10 — Срочное действие
Повторно SBP >180 или DBP >120:
* с опасными симптомами → экстренный маршрут;
* без симптомов → срочный контакт со специалистом.
Кнопка:
* «Позвонить в экстренную службу»;
* либо «Срочно связаться со специалистом».
SCR-BP11 — Домашний мониторинг
Запускается только если:
* давление повторно повышено;
* либо недостаточно валидных домашних данных.
Протокол:
* предпочтительно 7 дней;
* утром и вечером;
* два измерения за сессию;
* пауза 60 секунд.
Показывает:
* текущий день;
* следующую сессию;
* валидные сессии;
* пропуски;
* соблюдение.
Кнопки:
* «Начать утреннее измерение»;
* «Начать вечернее измерение»;
* «Как измерять правильно».
Это сценарий внутри «Здоровье → Давление». В Плане могут отображаться только напоминания.
SCR-BP12 — Итог мониторинга
Показывает:
* домашнее среднее;
* утреннее среднее;
* вечернее среднее;
* валидные сессии;
* соблюдение;
* устройство.
Домашнее среднее SBP ≥135 и/или DBP ≥85 создаёт маршрут клинической оценки.
Кнопки:
* «Скачать отчёт»;
* «Поделиться файлом»;
* «Вернуться к давлению».
6.6. Пульс
SCR-HR01 — Пульс
Показывает:
* текущий пульс;
* пульс в покое за день, 7 и 30 дней;
* личный диапазон;
* отклонение;
* контекст;
* источник;
* качество;
* время.
Кнопки:
* «Проверить пульс»;
* «История»;
* «Почему?».
SCR-HR02 — Повторная проверка
Показывает просьбу спокойно сесть и дождаться стабильного сигнала.
Кнопки:
* «Повторить измерение»;
* «Отмена».
SCR-HR03 — Контекст и симптомы
Поля:
* длительность;
* активность;
* сон;
* температура;
* симптомы;
* препараты, влияющие на пульс.
Кнопки:
* «Продолжить»;
* «Пропустить необязательные поля»;
* «Назад».
SCR-HR04 — Результат пульса
Варианты:
* устойчиво >100 в покое → клиническая оценка;
* очень высокий в покое → повтор, симптомы и ЭКГ;
* низкий с симптомами → safety;
* низкий без симптомов и соответствует личному уровню → информационное сообщение;
* недостаточно истории → продолжить сбор;
* нерегулярный → STATE-HR03A.
Кнопки:
* «Записать ЭКГ»;
* «Повторить измерение»;
* «Продолжить сбор»;
* «Связаться со специалистом».
Показывается только одно главное действие.
STATE-HR03A — Нерегулярный пульс
Объяснение:
«Часы или браслет заметили неравные интервалы между ударами. Это не диагноз аритмии или ФП».
Кнопка:
* «Записать ЭКГ».
SCR-HR05 — История пульса
Показывает отдельно:
* дневной пульс;
* пульс в покое;
* пульс во сне;
* пульс при нагрузке;
* события и их длительность;
* минимум, максимум, среднее;
* симптомы и контекст.
6.7. ВСР
SCR-HRV01 — Вариабельность сердечного ритма
Показывает:
* одну основную метрику;
* единицу;
* личный диапазон;
* статус сбора;
* устройство;
* протокол;
* время;
* качество.
Кнопки:
* «Посмотреть результат»;
* «Как собирается личный уровень»;
* «Почему?».
STATE-HRV01A — Собираем личный уровень
Показывает:
* сколько валидных ночей собрано;
* сколько ориентировочно осталось.
Ориентиры:
* первые выводы — примерно после 7 ночей;
* устойчивый диапазон — обычно после 14–21 ночи.
SCR-HRV03 — Результат ВСР
Варианты:
* одно отклонение → наблюдать;
* устойчивое отклонение → оценить со сном, пульсом, нагрузкой и температурой;
* нерегулярные интервалы → предложить ЭКГ.
Кнопки:
* «Продолжить наблюдение»;
* «Повторить измерение»;
* «Записать ЭКГ»;
* «Почему?».
ВСР сама не запускает экстренный сценарий.
STATE-HRV02A — Данные нельзя сравнить
Причины:
* сменилось устройство;
* изменился протокол;
* запись короткая;
* много артефактов;
* мало валидных интервалов.
Кнопки:
* «Повторить измерение»;
* «Продолжить сбор нового личного уровня».
SCR-HRV04 — Детали ВСР
Показатели при наличии:
* RMSSD;
* lnRMSSD;
* SDNN;
* pNN50;
* SD1;
* SD2;
* SD1/SD2;
* HF;
* LF;
* VLF;
* длительность;
* средний пульс;
* процент артефактов;
* процент валидных интервалов;
* положение;
* протокол.
Vendor score показывается отдельно как оценка производителя.
6.8. SpO₂
SCR-SPO01 — Насыщение крови кислородом
Показывает:
* последнее разовое значение;
* среднее за последнюю пригодную ночь;
* источник;
* время;
* качество;
* доверие;
* индивидуальную цель при наличии.
Кнопки:
* «Измерить сейчас»;
* «Показатели во время сна»;
* «Почему?».
SCR-SPO02 — Разовое измерение
Инструкции:
* спокойно сидеть;
* не двигаться;
* дождаться стабильного сигнала.
Сохраняет:
* SpO₂;
* индекс перфузии;
* устройство;
* режим;
* контекст;
* длительность;
* время.
Автоматическая проверка
Система сама проверяет:
* движение;
* помехи;
* стабильность;
* длительность;
* пригодное время ночной записи.
Доверие:
* A — медицинский пульсоксиметр;
* B — проверенное носимое устройство;
* C — потребительские часы/браслет;
* D — неизвестный источник.
SCR-SPO03 — Результат
Маршрутизация:
* ≥95% → обычное наблюдение;
* 93–94% один раз → повторить в покое;
* 93–94% устойчиво → подтвердить;
* 90–92% с носимого устройства → подтвердить медицинским прибором;
* подтверждённые 90–92% → клиническая оценка;
* <90% → срочный сценарий;
* очень низкое значение с серьёзными симптомами → экстренный сценарий.
STATE-SPO02A — Результат нельзя оценить
Причины:
* движение;
* помехи;
* нестабильный сигнал;
* короткая запись;
* недостаточно ночных данных.
Кнопка:
* «Повторить в покое».
SCR-SPO05 — Подтверждение
Кнопки:
* «Измерить подключённым прибором»;
* «Ввести результат вручную»;
* «Продолжить».
Пользователь не должен самостоятельно менять кислород.
SCR-SPO06 — Срочное действие
Кнопка:
* «Срочно связаться со специалистом»;
* либо «Позвонить в экстренную службу».
SCR-SPO07 — SpO₂ во время сна
Показывает:
* среднее;
* минимум;
* T90;
* ODI3/ODI4;
* число, частоту и длительность снижений;
* пригодное время записи.
Кнопки:
* «Выбрать ночь»;
* «Почему?»;
* «Обсудить дыхание во сне со специалистом».
Повторные снижения — скрининговый сигнал, а не диагноз апноэ. ODI не равен AHI.
6.9. ЭКГ
SCR-ECG01 — ЭКГ
Показывает:
* последнюю запись;
* пульс;
* дату;
* длительность;
* источник;
* качество;
* вывод устройства;
* вывод AxMed;
* превью сигнала при наличии.
Кнопки:
* «Записать ЭКГ»;
* «Открыть запись».
Статуса внутренней проверки врачом нет.
STATE-ECG01A — Нет устройства с ЭКГ
Текст:
«Для записи ЭКГ нужно совместимое устройство. Телефон сам не записывает ЭКГ».
Кнопки:
* «Пройти ЭКГ в клинике»;
* «Подключить устройство»;
* «Отмена».
SCR-ECG02 — Подготовка
Показывает:
* запись запускается на подключённом устройстве;
* нужно спокойно сесть;
* проверить контакт электродов;
* длительность 30–45 секунд.
Кнопки:
* «Начать запись»;
* «Отмена».
SCR-ECG03 — Запись
Показывает:
* таймер;
* контакт;
* прогресс.
Сохраняет:
* исходный сигнал;
* частоту дискретизации;
* длительность;
* тип отведения;
* устройство;
* артефакты.
STATE-ECG03A — Плохая запись
Кнопки:
* «Повторить запись»;
* «Как улучшить контакт».
SCR-ECG05 — Результат
Варианты:
* «Ритм выглядит регулярным»;
* «Возможна фибрилляция предсердий»;
* «Низкий пульс»;
* «Высокий пульс»;
* «Нерегулярный ритм»;
* «Результат неясен»;
* «Запись плохого качества».
Кнопки:
* «Скачать или поделиться ЭКГ»;
* «Повторить запись»;
* «Добавить симптомы»;
* «Почему?».
Ограничения:
* возможная ФП не является диагнозом;
* регулярный ритм не равен подтверждённому синусовому ритму;
* нормальная носимая ЭКГ не исключает острый коронарный синдром.
SCR-ECG06 — Скачать или поделиться ЭКГ
Кнопки:
* «Скачать ЭКГ»;
* «Поделиться с врачом»;
* «Отмена».
Создаётся файл с записью и метаданными. Проверка происходит вне приложения.
SCR-ECG08 — Срочное действие
Нарушение ритма с серьёзными симптомами ведёт в срочный или экстренный сценарий.
Боль в груди сохраняет safety-маршрут даже при нормальном результате носимой ЭКГ.
Подтверждённая ФП
Нагрузка ФП может вычисляться только:
* после подтверждения врачом;
* при достаточном времени наблюдения;
* при наличии доверенного способа передать подтверждение в AxMed.
Так как врачебного кабинета нет, этот сценарий не активируется, пока не реализован верифицированный импорт внешнего заключения.
Самостоятельная отметка пользователя не считается подтверждением врача.
6.10. Активность
SCR-ACT01 — Активность
Показывает:
* шаги;
* расстояние;
* активные минуты;
* умеренные и интенсивные минуты;
* силовые дни;
* сидячее время;
* длинный период без движения;
* личный уровень;
* источник;
* свежесть.
Кнопки:
* «Открыть цель»;
* «Добавить тренировку»;
* «Почему?».
STATE-ACT01A — Собираем личный уровень
Период:
* первые 7–14 дней.
Показывает:
* сколько дней собрано;
* какие данные доступны;
* чего не хватает.
После достаточного периода система предлагает личную цель.
SCR-ACT03 — Личная цель
Ориентиры:
* 150–300 минут умеренной активности;
* или 75–150 минут интенсивной;
* силовые минимум 2 дня.
Шаги увеличиваются постепенно. 10 000 не является обязательной медицинской нормой.
Кнопки:
* «Добавить цель в План»;
* «Изменить цель»;
* «Назад».
STATE-ACT03A — Умеренно повысить
Показывается только при:
* хорошем выполнении;
* благоприятном восстановлении;
* отсутствии симптомов.
Кнопки:
* «Обновить цель в Плане»;
* «Оставить текущую цель».
STATE-ACT04 — Адаптировать цель
Варианты:
* частично выполнено → сохранить или упростить;
* низкое выполнение → уменьшить и спросить о препятствии;
* напряжение восстановления → не повышать;
* высокий риск → оценка специалиста до интенсивной нагрузки.
SCR-ACT05 — Добавить тренировку
Поля:
* тип;
* дата;
* длительность;
* пульс;
* RPE;
* симптомы;
* группы мышц;
* расстояние;
* темп;
* высота;
* GPS.
Кнопки:
* «Сохранить тренировку»;
* «Отмена».
При ненадёжном пульсе используются RPE и Talk Test.
SCR-ACT06 — Детали тренировки
Показывает:
* длительность;
* средний и максимальный пульс;
* зоны;
* расстояние;
* темп;
* высоту;
* RPE;
* симптомы;
* восстановление пульса через 1 и 2 минуты;
* источник;
* качество.
Safety активности
Боль в груди, обморок, выраженная одышка или нарушение ритма прерывают обычный План.
Высокая нагрузка сама по себе не означает плохое восстановление.
6.11. Температура
SCR-TEMP01 — Температура
Показывает отдельно:
* температуру кожи с часов/браслета;
* температуру тела с медицинского термометра.
Для записи:
* источник;
* место;
* время;
* режим;
* качество.
Кнопки:
* «Добавить измерение»;
* «Температура кожи»;
* «Температура тела»;
* «Почему?».
SCR-TEMP02 — Температура кожи
Показывает:
* личный ночной диапазон;
* отклонение;
* длительность;
* контекст;
* качество.
Ориентиры:
* первые выводы примерно после 7 ночей;
* устойчивый диапазон после 14–21 ночи.
Температура кожи не диагностирует инфекцию или лихорадку.
SCR-TEMP03 — Температура тела
Поля:
* значение;
* единица;
* место;
* дата;
* время;
* источник;
* симптомы.
Кнопки:
* «Сохранить измерение»;
* «Отмена».
Только BODY_CLINICAL ≥38,0 °C создаёт сигнал диапазона лихорадки.
SCR-TEMP04 — Результат
Для термометра:
* абсолютное значение;
* сообщение о диапазоне лихорадки.
Для часов:
* отклонение от личного ночного уровня.
Кнопки по ситуации:
* «Измерить температуру тела термометром»;
* «Указать симптомы»;
* «Готово»;
* «Почему?».
STATE-TEMP04A — Данные нельзя оценить
Причины:
* устройство сняли или недавно надели;
* душ;
* нагрузка;
* плохой контакт;
* мало ночных данных;
* неизвестный тип;
* ошибка датчика.
Кнопка:
* «Повторить измерение».
6.12. Восстановление
SCR-REC01 — Восстановление
Пользовательские состояния:
* «Стабильно»;
* «Есть небольшое отклонение»;
* «Несколько показателей изменились»;
* «Выраженное отклонение»;
* «Недостаточно данных».
Основные входы:
* ВСР;
* пульс в покое;
* сон при наличии.
Контекст:
* нагрузка;
* температура кожи;
* SpO₂;
* симптомы;
* болезнь;
* алкоголь;
* поездка;
* лекарства;
* цикл;
* беременность;
* высота;
* хроническое состояние.

* источник;

* длительность;

* причина действия.
Высокая активность без неблагоприятных изменений не считается отрицательным фактором.

Порядок:

3. полнота;
4. свежесть;
5. личный уровень;
6. длительность;
7. согласованность;
8. уверенность;
9. одно следующее действие.

9. Межблочные правила
* Центральное распределение жира + повышенное давление повышают приоритет кардиометаболической оценки.
* Возможный низкий мышечный компонент + отсутствие силовых повышают приоритет силовой цели.
* ВСР вниз + пульс в покое вверх усиливают сигнал восстановления.
* Рост нагрузки + неблагоприятные изменения ВСР/пульса/сна может снизить цель.
* Температура кожи вверх + пульс вверх + ВСР вниз усиливают физиологический сигнал.
* Ночные снижения SpO₂ + храп + центральное распределение жира + давление создают скрининг дыхания во сне.
* Нерегулярный PPG ведёт к ЭКГ.
* Safety всегда выше Главной, Восстановления и Плана.
10. Хранение и backend
Для каждой записи хранятся:
* timestamp и timezone;
* источник;
* устройство;
* firmware/SDK;
* контекст;
* качество;
* доверие;
* единица;
* original value;
* normalized value;
* версия алгоритма;
* версия референса.
Правила:
* исходные записи неизменяемы;
* исправление создаёт новую версию;
* vendor-поля не превращаются автоматически в стандартные метрики;
* повторная синхронизация не создаёт дубликаты;
* смена устройства запускает пересчёт личного уровня;
* UI не рассчитывает медицинские статусы;
* пороги не зашиваются в приложение.
Backend передаёт раздельно:
* физиологический статус;
* уверенность;
* срочность;
* визуальную выраженность;
* главное действие;
* дополнительные действия;
* reason codes.
11. Безопасность
Порядок обработки:
1. качество;
2. источник и доверие;
3. контекст;
4. индивидуальная цель;
5. доменная опасность;
6. тяжёлые симптомы;
7. safety override;
8. обычный вывод и План.
Опасные симптомы:
* боль в груди;
* обморок;
* выраженная одышка;
* неврологические симптомы;
* резкое ухудшение.
Обязательные ограничения:
* плохой сигнал не считается нормой;
* нормальная носимая ЭКГ не исключает острый коронарный синдром;
* ВСР и температура кожи сами не создают emergency;
* PPG не диагностирует ФП;
* ODI не диагностирует апноэ;
* BIA не ставит диагноз;
* приложение не меняет лекарства, кислород или дозировки;
* при тяжёлых симптомах safety может сработать без ожидания подтверждения;
* экстренные номера и тексты локализуются.

13. Критерии приёмки
Версия готова к пилоту, если:
* есть только четыре нижние вкладки;
* реализовано ограничение 18+;
* все кнопки имеют конкретные названия;
* служебные проверки не показаны как экраны;
* приложение работает без устройств;
* у показателей есть время, источник и качество;
* Body работает без BIA;
* 3D-модель не является диагностической;
* давление разделяет дом, клинику, СМАД и wearable;
* поддерживаются два измерения и пауза 60 секунд;
* HBPM запускается только по условию;
* нерегулярный PPG ведёт к кнопке «Записать ЭКГ»;
* без ЭКГ-устройства предлагается клиника или подключение;
* SpO₂ разделяет разовое и ночное измерение;
* температура кожи не смешивается с температурой тела;
* Восстановление не показывает балл 0–100;
* План не меняет лекарства;
* отчёт и ЭКГ передаются файлами;
* врачебного кабинета нет;
* safety имеет высший приоритет;
* смена устройства запускает пересчёт;
* история не перезаписывается;
* все пороги версионируются;
* каждый вывод имеет reason codes и объяснение «Почему?».
